The release overlay contains this project's payload and source, rebuilt VKD3D-Proton and altered x64 DXGI with their corresponding sources and notices, and the unmodified official DXVK-NVAPI release archive. It does not bundle the GE-Proton base archive. Its installer fetches that official base and verifies the pinned hash before assembling a runner locally. `tools/build-runner.py` packages this repository's source, notices, and input/output hash manifest under `files/share/mw4/`. It preserves the upstream runner's files except for the explicitly recorded runtime replacements and launcher metadata. Python bytecode caches are excluded.

The overlay's `renderer/source.tar.xz` contains VKD3D-Proton, dxil-spirv, and all recursive submodule sources at the revisions recorded in its manifest. The complete upstream license files remain in those sources, and renderer notices also accompany the DLLs. The project's own source and build scripts are included directly in the overlay. [Build instructions](docs/build.md#package-a-release-overlay) describe packaging and rebuilding. No game executable, original driver, game resource, shader dump, icon, or save belongs in the release archive.

The overlay's `nvapi/dxvk-nvapi-v0.9.3.tar.gz` is pinned to SHA-256 `284033c38e463ba31d40466d650d0c411df6f64bbf8ed3d19c9ca0cadf31dfd3`. The x86_64 runner installs its 32-bit NVAPI DLL, 64-bit NVAPI and NVOFAPI DLLs, and Linux Vulkan Reflex layer. The layer manifest's library path is adjusted to the existing GE layout; the binaries are unchanged. ARM64 binaries and upstream test executables remain in the archive but are not installed into this x86_64 runner. The runner manifest records the original component hashes and installed output hashes. The MIT notice is installed under `files/share/mw4/licenses/DXVK-NVAPI-LICENSE`.

Beta.3's `dxgi/source.tar.xz` contains the altered DXVK source and all recursive submodules selected by that exact revision, including dxbc-spirv, libdisplay-info, Vulkan/SPIR-V headers and MinGW DirectX headers. Their original license files remain in the archive. Collected notices also accompany the DLL under `dxgi/licenses/` and the installed `files/share/mw4/dxgi/licenses/`. `MW4-PATCHES/` in the source archive identifies GE's prep script and patches and the local budget-only change. This is an altered build, not an unmodified upstream DXVK release. Only the x64 DXGI DLL is replaced; the GE base supplies the other DXVK components.
